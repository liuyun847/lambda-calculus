# λ 演算迷你语言（lambda-calculus）

一个**零依赖、单文件**的 λ 演算解释器实验：把 `x:y:x` 这样的字符串解析成项（AST），
再按最左最外（normal order）策略逐步 β / η 归约，打印每一步与最终结果；对不收敛的项
（Ω、Y 组合子自应用）有循环检测与步数上限，**不会死循环**。

## 目录内容

| 文件 | 作用 |
|---|---|
| [write.py](write.py) | 解释器本体：词法/解析、项的表示、α 改名与替换、单步归约、过程打印、发散标记 |
| [lbd.py](lbd.py) | 演示脚本：用该解释器跑布尔/条件函数，并用 **Python 原生 `lambda`** 把同样的东西再实现一遍做对照 |

> `lbd.py` 里是 `from write import Lambda`，所以两者必须放在同一目录。

## 快速开始

```powershell
# 在仓库根目录（clone 下来的目录）执行
python write.py     # 跑 write.py 里的自测（≈9 组用例）
python lbd.py       # 跑布尔/条件的对照演示
```

作为库用：

```python
from write import Lambda

lc = Lambda()                        # 每个实例自带独立 env 与新鲜名计数器
print(lc.run("n=x:y:x\nm=n(a)\nm"))  # run：返回过程与结果的字符串
lc.run_p("m")                        # run_p：同上，但直接打印（返回 None）
```

## 语法

三种语句，一行一条：

```text
x:y           定义（λ 抽象，可链式 x:y:z 表示多参数）
n=x:y         赋值（把项绑定到名字 n，不预先归约）
m=n(a)        调用（应用，可链式 n(a)(b)，可原地(x:y)(a)）
```

- 标识符首字符可为字母、下划线或数字（`0`、`1` 可直接当变量名，方便写丘奇数），
  其后还可含 `$` 与 `'` —— 因此内部新鲜名（`x$1`）和展示用的去歧义名（`y'`）都能回灌。
- 应用只写成 `f(a)` 形式（带括号），不省略括号，避免歧义。
- 名字与标准 λ 演算记号的对应：`x:y:x` ≡ `λx.λy.x`，`f(a)` ≡ `f a`。

`Lambda` 实例的 `env` 在多次调用间持久（同名赋值会覆盖）；要干净环境就新建实例。

## 归约策略

**最左最外（normal order），β + η**：

- 最外层若是 redex ⇒ 立刻 β 收缩；
- 否则步进函数侧；函数侧已是范式且非 λ，再步进参数侧；
- λ 体内部**仅在没有任何更外层可归约项时**才进入（这点区别于旧版：`(x:y:omega)(a)`
  会在第一步就 β 成 `y:omega`，而不是卡在 λ 体内部的 redex 上）；
- η：`λv.(f v)` 且 `v` 不在 `f` 中自由出现 ⇒ `f`。头部是 β-redex 时 β 优先，所以只有
  "孤立"的 λ 才会被 η 收掉（如 `b:x:y:b(x)(y)` ⇒ `b:x:b(x)`）。

## 防死循环

- **循环检测**：在 α 等价意义下重复出现的项 ⇒ 判定不收敛（如 `(x:x(x))(x:x(x))`）。
- **步数上限**：超过 `max_steps`（默认 100）仍未收敛 ⇒ 判定发散（如 Y 组合子的无限展开）。

发散时「结果」行显示 `⟂ 发散(…)` 标记，不会把程序挂住。α 等价键会把形如 `name$N`
的新鲜名按「基名 + 首次出现顺序」归一化，所以同一步骤间被编成 `x$1` / `x$3` 的项仍能判等。

## 输出示例

```text
if(t)(a)(b):
  · if(t)(a)(b)
  ⇒ (b:x:y:b(x)(y))(t)(a)(b)
  ⇒ (x:y:t(x)(y))(a)(b)
  ⇒ (y:t(a)(y))(b)
  ⇒ t(a)(b)
  ⇒ (x:y:x)(a)(b)
  ⇒ (y:a)(b)
  ⇒ a
结果: a
```

步骤 ≤ 12 时全部列出；更多则只列前 5 步与最后 3 步，中间以 `… 共 N 步 …` 折叠。
脚本中只要出现过调用语句，「结果」行就打印最后那次调用的归约结果（赋值语句本身不归约）。

## λ 演算背景（速览）

只用**变量、函数抽象、函数应用**三种项，就能表达一切可计算函数：

```text
e ::= x         变量
    | λx. e     函数抽象
    | e1 e2     函数应用
```

核心规则是 **β 归约** `(λx.e) a → e[x := a]`（把 `e` 中自由的 `x` 换成 `a`），
另有 **α 变换**（变量重命名，`λx.x ≡ λy.y`）与 **η 归约**（`λx.f x → f`，当 `x ∉ FV(f)`）。

常见编码：

```text
TRUE  = λx.λy.x          FALSE = λx.λy.y          IF = λb.λx.λy.b x y
0 = λf.λx.x              1 = λf.λx.f x            2 = λf.λx.f (f x)
SUCC = λn.λf.λx.f (n f x)
Y = λf.(λx.f (x x))(λx.f (x x))      # 不动点组合子，用于递归
```

因此 λ 演算是**图灵完备**的，与图灵机等价；它是 Haskell / OCaml / Scheme 等函数式语言的
核心模型，也是程序语言语义、类型系统（Curry–Howard 同构、Coq/Lean）的基础。

## 已知边界

- 无类型、无内建数字/布尔/列表——一切靠丘奇编码。
- 栈式递归解析，超长链式应用可能触及 Python 递归上限。
- 归约到范式即停；不做惰性求值优化、不保留求值历史树。
